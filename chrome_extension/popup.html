What does Copy as .env do?
  1. Click Copy as .env.
  2. In the project folder, open the file named .env (or create it), replace everything in it with what you copied, and save.
  3. Run uv run python run_all.py.

Your login values never leave this browser: the extension only reads them and copies them to your clipboard. Treat them like a password and don’t share them.
